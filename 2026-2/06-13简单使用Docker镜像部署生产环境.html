简单使用 Docker 镜像部署生产环境

最近有好几个我自己的需求要我把东西部署到云服务器上，打卡提醒闹钟，QQ 机器人云云……每次都 scp 过去，或者用 git 同步，其实还是难受（再说这个打卡提醒闹钟是私人的东西，要发只能发 private 仓库，又要设置密钥设置 ssh config……）。

但其实更大的问题是——你跑的是应用，应用就要整成 service，整监控整健康检查，即使是最简单的。如果你自己部署，那你自己写 systemd 吧！虽然 AI 也能写，但终究还是麻烦，但现在有了 docker 了，你可以依赖它了。

顺便，一个方便获取国内可用镜像源的地方 https://github.com/dongyubin/DockerHub ，可惜没有结构化地展示出来而是用 markdown 写的，让 AI 解析吧。

这里简单处理：

  1. 在生产服务器上直接跑一个最简 Docker 仓库
  2. 将自己的应用打包成 Docker 镜像并直接推过去
  3. 在生产环境上用 docker-compose 直接部署镜像
  4. Dockerfile 和 docker-compose.yml 都可以让 AI 去写，注意 Dockerfile 的增量传输机制，避免无谓的缓存失效

但这里的一个问题是……第一次跑的时候，你 FROM 的镜像也会由你的客户端推给服务端，带宽捉急哦！
