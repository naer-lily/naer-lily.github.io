学习路径没有最优解

几个稍加思考就能认识到的事实：

  1. 对别人来说效率 100% 的路，对你来说效率不一定（或者说，一定不）是 100%
  2. 0% x 0 = 100% x 0 << 50% x 100，效率 100% 却让你止步不前的路，等于效率为 0%，效率 50% 却能让你一直走下去的路远好于此
  3. 在走一条路之前，你是不知道它的效率几何的，而在开始走之后，你还能调整方向
  4. 实际上，根本就没有效率 100% 的路，这只是理论存在，你绝无可能彻底找到它，你倘若硬是要追求它，你几乎必定会耽搁走路

实际的学习路径会像一颗动态生成的有向无环图（想想杀戮尖塔这类游戏的地图），你面前总是有无数种选择，你不知道哪种选择是最优的，你不知道做完这个选择后后面会看到什么，你唯一能做的，就是找到一个看着可以走下去的路，然后走下去。

在我们的心智模型中，这是一个图，而非树——你和终点（即使那对你也只是一个模糊的印象）之间是有无数条路的，没有一个选择会彻底决定你的成败，暂时走远了路，你也可以在后续绕回来。

但话又说回来，岔路对你同样有意义，知道这条路不能走，知道这么走会发生这种情况，这本身也对你的学习有意义。重点是和自己比，在这颗动态生成的图里面，唯有你过去走过的路是彻底清晰的。

但倒也不能一概而论，绘画按照 V 大的理论是很螺旋上升的，我也认同这一点，但这可以说是视角不同了，可以说我的视角其实是聚焦于我在图中的一个具体的节点，我面前有无数条路，我该往那条路走，还是驻足不前反复研究，我回答的是这么一个具体的问题。最关键的还是，走下去。
