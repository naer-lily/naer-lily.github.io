01 · 心智模型与方法论

1. 三层模型

层是什么旋钮何时进入
业务层工作流：选哪些组件、怎么连接ControlNet 强度、denoise、参考图通道、LoRA 通道第 1–4 周
参数层组件上的数值CFG、步数、采样器、种子第 5 周起
对比层控制变量实验每次只变一个最后

关键区分：ControlNet 强度与 denoise 是业务层旋钮（改变工作流行为，值得比较）；步数/CFG/采样器是参数层旋钮（渲染细节，默认值即可）。

2. 控制通道的效力排序（W1 里谁在干活）

ControlNet 线稿强度  >  denoise 幅度  >  负向提示词  >  正向提示词
1
  • "修正结构"的真实机制：模型先验 + 上述旋钮，不是提示词在发指令
  • 提示词是描述（画面里有什么），不是指令（帮我改什么）
  • 标签系模型（NoobAI）里，句子提示词基本无效，必须用标签

3. 反馈的两种类型（平行基线的划分依据）

类型机制练什么代表
隐性纠错你不指出错误，模型先验沿你的线"顺手修正"，你读差异发现盲区（自己没注意到的错）W1 贴线重绘
显性纠错你必须先说"哪里错了、怎么错"，模型再改诊断眼（改好了=诊断对，改不好=诊断错或模型不行）W2/W3 指令修图

聊天模型讲评已被实测否决：反馈由修图动作本身承担，不讲评、直接改给你看。

4. 两个目标水位线（并存，别互相替代）

水位线查什么说明
平均画师版（W1-B）基本功错误（解剖/比例/透视/明暗/线条/构图）重绘不加任何风格约束
老师风格版（W5）与特定画师的风格距离IP-Adapter（浅）或 LoRA（深）

目标水位线换成老师后，差异分类多一类：风格距离——它是学习目标，不是错误。

5. 浅拷贝 vs 深拷贝（风格获取的两种模型）

IP-Adapter / 多参考跟随风格 LoRA
发生时机推理时（零训练，即时生效）训练时（一次投入，长期复用）
复制深度表层统计：配色、笔触、渲染质感更深：风格分布被烙进模型
漂移单图会漂移，3–5 张多参考才稳稳定
换老师成本换参考图即可重新训练
本质比喻指着一道菜说"照这个做"厨师进修这门菜系

边界（诚实版）：两者都抓不住作者的构造逻辑（为什么这么构图、怎么理解体积）——"为什么"仍靠你的自评临摹分析，AI 给的是"像"，你学的是"为什么像"。

6. 组件语义词典

组件是什么 → 在你的工作流里扮演什么 → 默认 → 何时动
底模（NoobAI）画师人格 → 决定重绘结果不跑成写实风 → — → 想换画风领域时（换模型=换画师）
CLIP 文本编码器把标签翻译成向量 → 提示词入口 → 无需 clip skip（官方） → 不动
VAE潜空间↔像素转换器 → img2img 的 Encode/Decode → SDXL 自带 → OOM 时用 tiled VAE
正向提示词描述"画面里有什么" → WD14 自动生成 → 官方前缀+内容标签 → 内容不匹配时微调
负向提示词错误压制通道 → "修正手/解剖"的主要文字通道 → 官方模板（见 03） → 加词观察
采样器+步数噪声→图像的路径规划器 → — → Euler a / 28 步（官方） → 第 5 周起
CFG提示词服从强度 → — → 5（官方区间 3~6） → 过饱和/不听指挥时 ±1
种子随机起点 → 比较时必须固定 → — → 换构图才换
分辨率出图尺寸 → 原画比例就近选档 → 官方列表（见 03） → 低于 512×512 会出错
ControlNet结构通道（管骨架） → 把你的线稿当约束 → 强度 0.8（A）/0.3（B） → 0.3~1.0 都试过再定
预处理器画→引导图翻译器 → LineartAnime 提取线稿 → — → 换引导类型时
denoise改动幅度 → 半贴线重画的甜区 → 0.45（A）/0.65（B） → 0.3~0.7 扫描
WD14 Tagger图→标签 → 自动提示词/训练打标 → — → 标签不准时手动改
LoRA风格/概念补丁 → 老师浓度旋钮（weight） → 0.6~1.0 → 过拟合/欠拟合时调
IP-Adapter零训练风格跟随 → 老师风格即时通道 → weight 0.6~0.9 → 见 05

7. 多人场景能力边界（画双人/多人互动时）

三个能力层，各有各的工具，纯标签做不到"A 做 X、B 做 Y"：

层工具说明
人数标签 2girls/3girlsNoobAI 原生支持（Danbooru 语料）；WD14 自动打
各自动作OpenPose ControlNet 多骨架（Chenkin 含 OpenPose 模式；DWPose 预处理器提取多人骨架）"谁做什么"的结构层：每角色一根骨架；骨架可自己摆、可从参考图/自己的画提取
各自身份角色标签/LoRA + 区域条件（ComfyUI area/region conditioning：mask 分区域各挂 LoRA 与提示词）⚠️ 特征串扰是真实问题（LoRA 互相污染）→ 区域 mask + 权重调低 + 角色特征差异拉大
语义指代（事后修改）W3 指令编辑（Qwen-Image-Edit 系列以多角色一致性编辑为主打）"把左边女孩的头发改蓝"式指代；云端/租卡

边界：标签是全局描述；互动"自然感"是模型统计弱点（摆拍感）——这正是你的建构空间：AI 给互动结构的普遍性，你负责情境与自然感的集中性（对应 §1.5 的哲学分工）。双人图同样跑 AI 反馈闭环，差异自读"构图"类多一个维度：互动关系（视线、距离、接触点、重心）。

8. 防坑清单

  1. 自评永远在前（顺序反了就是抄作业）
  2. 区分"错误"和"风格差异"（AI 会正常化你的个人笔触，那不是你的失败）
  3. ControlNet 强度是旋钮不是开关
  4. 工作流 B（平均画师版）不要加"保持我的风格"
  5. 比较时固定种子
  6. OOM 三板斧：降分辨率（768）+ Hires fix / tiled VAE / 少加载
