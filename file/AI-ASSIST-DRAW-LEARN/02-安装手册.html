02 · 安装手册（Windows + 4060 8G + 国内网络）

所有链接均经 HTTP 实测（状态码 + 文件大小）。下载顺序 = 表格顺序。

1. 下载清单

#东西大小直链
1ComfyUI 便携包（cu126）1.98GBhttps://github.com/Comfy-Org/ComfyUI/releases/latest/download/ComfyUI_windows_portable_nvidia_cu126.7z（慢就加 https://ghproxy.com/ 前缀）
24 个自定义节点小见 §2

5. 报错速查

报错解法
No module named xxxManager → 节点 → Install missing dependencies
CUDA out of memory见 01 §7 三板斧
模型列表空文件放错文件夹（§2 路径）
ControlNet 不兼容Chenkin 必须用 Advanced ControlNet 节点（不能用原生节点）
Tagger 下载卡住设 HF_ENDPOINT 后重启
端口占用bat 加 --port 8189
