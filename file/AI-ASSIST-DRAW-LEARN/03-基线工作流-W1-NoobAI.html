03 · 基线工作流 W1 — NoobAI 贴线双通道

1. 工作流 A — 结构修正版（贴着我的线，修我的错）

[Load Image]  ←你的画
   ├──→ [WD14 Tagger] ──→ 标签 ──→ [CLIP Text Encode]（正向：官方前缀 + 内容标签）
   │                                   [CLIP Text Encode]（负向：官方模板）
   ├──→ [预处理器 LineartAnime] ──→ [Advanced ControlNet]（Chenkin，Lineart 模式，strength=0.8）
   └──→ [VAE Encode] ──→ [Latent]（img2img 起点，denoise=0.45）
                                          │
                        [KSampler] ←──────┘

语义：你的画同时走两条路——线稿被 ControlNet 抓走当骨架约束（贴线），原图被压进潜空间当起点（半改）。"修正解剖但保持构图" = 模型先验 + 两个旋钮，不是提示词在发指令。

2. 工作流 B — 理想完成版（平均画师水位线）

与 A 完全相同，只改两个旋钮：

  • ControlNet strength：0.8 → 0.3
  • denoise：0.45 → 0.65

⚠️ 不要加"保持我的风格"——加了就永远看不到成熟标准。

5. Chenkin-UniControl-XL 用法（必须注意）

  • 不能用 ComfyUI 原生 ControlNet 节点（官方 README 明确），必须用 ComfyUI-Advanced-ControlNet 插件的 Load Advanced ControlNet Model + Apply Advanced ControlNet 节点
  • 8 合 1 模式在节点下拉切换：Lineart / Canny / Depth / OpenPose / Tile / Inpaint 等——本工作流用 Lineart 模式
  • Fuse 模式可多条件合一（线稿+深度+姿势一次调用），示例见 controlnet-fuse.json
  • 许可：fair-ai-public-license-1.0-sd，禁止商用
