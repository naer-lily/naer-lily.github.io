04 · 平行基线 W2–W5

同一张画，跑不同"通道组合"做业务层对照。差异不是参数差异，而是反馈机制差异（见 01 §3）。

1. 反馈类型回顾

  • 隐性纠错（W1）：不指出错误，模型先验沿你的线顺手修正 → 发现盲区
  • 显性纠错（W2/W3）：你必须先诊断，模型再改 → 训练诊断眼

2. 各基线

W2 — FLUX.2 [klein] 4B 指令修图（本地）

  • 官方确认（README 实测）：单模型支持文生图/单参考编辑/多参考编辑；约 8GB 显存可跑（官方原话 RTX 3090/4070 and up）；Apache-2.0；2026-01-15 发布
  • ⚠️ 4060：显存达标但带宽低，分钟级；用 GGUF Q4_K + Qwen3-4B 编码器 + flux2-vae（下载见 02 §6）
  • ⚠️ 接入：官方仓库是 stable-diffusion.cpp 路线；ComfyUI 接入以 ComfyUI-GGUF 文档为准（未验证）
  • 来源：https://github.com/black-forest-labs/flux2

W3 — Qwen-Image-Edit 指令修图（云端）

  • 官方确认（README 实测）：20B、中英双语、外观编辑（局部增删改其余不变）+ 语义编辑（含风格迁移）、Apache-2.0
  • 运行：8G 本地跑不动完整版 → Qwen Chat 网页 / 阿里云 API / 社区 ComfyUI 工作流（Qwen Image Edit 2511 Ultimate）配租卡
  • 来源：https://huggingface.co/Qwen/Qwen-Image-Edit

W4 — FLUX.2 [dev] 32B（质量上限基准，可选）

  • 官方定位"最高质量"；非商用许可；24G+ 显存 → 租卡
  • 用途：偶尔租一次出"上限参考图"，校准目标水位线

W5 — 老师风格通道（详见 05 / 06）

  • 路线 0：画师标签（NoobAI 用完整 Danbooru 训练，知名画师自带标签，零成本，先试）
  • 路线 1：IP-Adapter 多参考风格跟随（零训练，即时）→ 05-风格路线-IPAdapter.md
  • 路线 2：风格 LoRA（深拷贝，一次训练长期复用）→ 06-风格路线-LoRA.md

3. 对照表

基线机制反馈类型提示词语言运行成本何时用
W1 NoobAI 双通道贴线重绘隐性纠错标签本地 8G¥0日常主通道
W2 FLUX.2 klein指令编辑显性纠错自然语言本地 8G（慢）¥0练诊断眼
W3 Qwen-Image-Edit指令编辑显性纠错中文/英文云端按次快速验证诊断
W4 FLUX.2 dev生成/编辑参考基准自然语言租卡按小时校准上限
W5 老师风格标签/参考/LoRA风格模仿混合混合混合追特定画师

4. 对照方法

  • 同一张画，各基线各出一版，归档"同画多通道"对照组（模板见 07）
  • 固定种子，否则差异混杂随机性
  • 所有通道都会正常化你的风格（表层复制）——"错误 vs 风格差异"分类照旧适用
  • 先跑通，再谈优化（第 3–4 周目标：W2 跑通一张 + W5 路线 1 验证）
