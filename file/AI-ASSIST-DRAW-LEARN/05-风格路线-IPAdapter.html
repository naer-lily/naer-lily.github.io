05 · 风格路线 — IP-Adapter（零训练风格跟随）

场景：想让 AI 按"某位老师的风格"重绘你的画，不想训练。个人学习、不公开传播。

1. 心智模型

  • IP-Adapter 是什么：一个作者已训练好的"风格翻译官"适配器——把参考图压缩成特征向量，注入生成过程的每一步，把输出"拉向"参考图的风格。零训练，推理时即时生效（查字典，不是背字典）
  • 复制深度：浅拷贝——配色、笔触质感、渲染风格等表层统计；抓不住构造逻辑（那是 01 §5 的边界）
  • 单图漂移，多图才稳：一张参考图的信息不够，给 3~5 张老师作品才锁得住
  • 与 ControlNet 正交：ControlNet 管骨架（长什么样），IP-Adapter 管风格（什么质感）——两者可叠加："老师风格的贴线重绘" = ControlNet（你的线）+ IP-Adapter（老师的风格）
  • 与 LoRA 的取舍（详见 06）：
IP-AdapterLoRA
训练无需要（20~60 张 + 1~2 小时租卡）
生效即时，每次传参考图加载即用，长期复用
稳定性多参考才稳稳定
换老师换图即可重训
深度浅深
用途验证方向、临时对比确定长期学某位老师

与 W1 组合成"老师风格贴线重绘"：在 W1 的节点链上，把 IPAdapter Advanced 的输出并联进 KSampler 的 model 输入（ControlNet 管线稿 + IP-Adapter 管风格）。

参数语义：

  • weight：风格强度。0.6~0.9 起步；太高 → 糊、内容丢失；太低 → 没风格
  • start/end（时间步区间）：默认全区间；若"风格压过结构"，把 end 调低（如 0.8）让后半程回归内容

4. 验证与调参

  1. 同一张画：无 IP-Adapter / weight 0.5 / 0.7 / 0.9 各出一张，固定种子
  2. 参考图数量：1 张 vs 3 张 vs 5 张对比（预期：1 张漂移明显）
  3. 与 W1-B（平均画师版）归档对比——差异 = 风格距离

5. 伦理

个人学习、不公开传播；别公开发布带老师风格化的输出；商用一律不行（模型本身禁止商用，仿冒在世画师风格商用是侵权风险）。

6. 未验证项

  • plus_vit-h 与 NoobAI 的具体融合效果需实测（SDXL 通用适配器，无 NoobAI 专属调优）
  • batch 合并节点的确切名称以安装后右键菜单为准
  • 参考图用老师原图 vs 用老师作品的线稿版，效果差异需自测
