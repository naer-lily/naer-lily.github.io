06 · 风格路线 — LoRA（深拷贝风格训练）

场景：确定长期学某位老师，训练一个"老师风格"模块，之后每次重绘都能调用。个人学习、不公开传播。

1. 心智模型

  • LoRA 是什么：训练阶段产生的"风格分布"小补丁——把老师作品的统计特征烙进模型（深拷贝）。推理时加载，一次训练、长期复用
  • 老师浓度 = LoRA 权重（0.6~1.0 是常用区间，见 §5）
  • 成本真相：贵的是你的时间（数据准备 ~半天），不是钱——训练 1~2 小时 × 6 元/小时 ≈ 6~12 元
  • 硬约束：4060 8G 本地训不了 SDXL（2026 训练指南实测：SDXL 需 ~10GB，fused backward pass + bf16；FLUX.2 klein 需 12~16GB）→ 必须租卡或云服务（来源：https://sanj.dev/post/lora-training-2025-ultimate-guide/ ）
  • 与 IP-Adapter：深 vs 浅、一次性投入 vs 即时、稳定 vs 漂移——先用 IP-Adapter（05）验证老师方向，再决定是否上 LoRA

2. 成本核算

项成本
租卡（AutoDL，如 RTX PRO 6000 96GB ≈ 6 元/小时）1~2 小时 ≈ 6~12 元
或云训练服务（Tensor.Art 工作坊，免环境折腾）按点数计，量级相当
数据准备（你的时间）~半天（一次性）
合计<50 元，长期复用

3. 数据准备（决定成败的一步）

要求：
- 精选 20~60 张：风格一致性 > 数量；剔除跨风格/崩坏/带文字的图
- 裁掉水印/签名；统一到 1024 附近（SDXL 原生分辨率，训练器自动 bucketing）
- 打标：每张图一个同名 .txt

打标工具：WD14 Tagger v3（SmilingWolf/wd-vit-tagger-v3，与 ComfyUI-WD14-Tagger 同族）
打标规则：
  - 统一风格标签：每张图都加同一个自定义标签，如 style_t_xxx
  - 保留内容标签（1girl、long hair 等）——删光内容标签会学成"题材绑定"
  - 不用画师真实名（避免与模型内已有画师标签打架 + 伦理）

参数说明（社区实践，来源：sanj.dev 2026 训练指南 + kohya 文档；以实际效果为准）：

参数风格 LoRA 建议值语义
network_dim32~64容量；越大越强越易过拟合
network_alphadim/2（16~32）与 dim 的比值影响强度
learning_rate1e-4（用 LoRA+ 时 5e-5 起步）太高发散，太低学不动
max_train_epochs10~20（或 steps 1000~3000）过拟合检测见 §5
optimizerAdamW8bit省显存
mixed_precisionbf1640 系卡支持
fused backward pass24G+ 卡不需要；8~12G 必须4060 本地不适用

执行地点二选一：

  1. AutoDL 租卡：租 24G+（4090 或 96G 卡）→ 终端里按上面流程装（镜像一般自带 CUDA，注意 torch cu124 匹配）→ 上传数据集 → 训练 → 下载产物 .safetensors → 关机（数据盘保留）
  2. Tensor.Art 工作坊：网页上传数据集、填参数，免环境搭建（https://learnai.tw/tensor-art-training-your-model/ ）

5. 过拟合检测与部署

text
训练产物 → ComfyUI\models\loras\style_t_xxx.safetensors

工作流：LoraLoader 节点（lora=style_t_xxx, strength=0.6~1.0）串在 Checkpoint 与 KSampler 之间

过拟合判断（固定种子下）：
  weight 1.0 → 风格极强但细节"僵死/糊/重复"  = 过拟合 → 降 epochs 或降 weight
  weight 0.6 自然、0.9 崩    = 训练过头 → 重训时减 epochs
  weight 1.0 风格仍弱         = 欠拟合 → 加 epochs 或加数据

6. 伦理与许可

  • 个人学习、不公开传播——最安全
  • 别公开发布训练出的 LoRA 或带老师风格的输出：模型许可（fair-ai-public-license-1.0-sd）要求衍生模型开源，公开会与原作者权益冲突；私用即可
  • 商用一律不行（模型禁止商用 + 仿冒在世画师风格是侵权风险）

7. 未验证项

  • 具体训练参数组合需按实际效果微调（上面是社区基准值）
  • AutoDL 上 kohya 环境的 CUDA 版本与 torch cu124 的匹配以镜像实际为准
  • 数据量 20 vs 60 张的收益拐点需自测
