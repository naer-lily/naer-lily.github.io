方法论总纲（一句话版）

业务层选通道、参数层用默认、对比层才较真。

  1. 业务层（第 1–4 周）：搭工作流，在工作流之间比较（ControlNet 强度、denoise、参考图通道、LoRA 通道）
  2. 参数层（第 5 周起）：才允许动 CFG / 步数 / 采样器，每次只变一个
  3. 对比层（最后）：严格的 A/B，仅用于解决具体问题

两条核心认知（详见 01）：

  • 提示词是"描述"不是"指令"——结构修正靠 ControlNet 强度 × denoise × 负向提示词，不靠句子
  • 反馈分两类：隐性纠错（贴线重绘，发现盲区）vs 显性纠错（指令修图，验证诊断）
